# セッション日付詳細（カレンダー日付クリック時）

## 目的
- その日の記録を素早く把握し、編集/削除/共有などの行動に迷わず到達させる

## 対象
- カレンダーの任意日付クリック時に表示する詳細ビュー

## UI形式
- PCはDialog、SPはDrawer/Bottom Sheetで表示（shadcn/ui優先）

## デザイン方針
- 全体は暖色系の静かな上質感、紙質感を意識する
- カードは薄い境界か影で面を表現し、角丸は24-32px基準
- 強調色は深いグリーン、CTAはダークブラウンを基本にする

## 情報優先度
1. 日付/曜日/時間帯
2. セッション概要（件数/満足度/総量）
3. 記録一覧
4. アクション

## 主要コンポーネント
- Dialog / Drawer
- Card / Badge / Chip
- Button / DropdownMenu / Tooltip
- Skeleton / Toast
- Separator / ScrollArea

## レイアウト指針
- ヘッダー: 日付（大）+ 曜日/時間帯（補助）+ 閉じる
- サマリー: 件数/平均満足度/総グラム数を横並びの小カードで表示
- 記録一覧: セッションカードを縦並び、各カードに「満足度」「場所」「フレーバー一覧（画像と名前）」を集約
- アクション: 主要CTAは「この日に記録を追加」、各カード内に編集/削除/共有

## セッションカード構成
- 先頭: 時刻 + 満足度アイコン（視線誘導）
- 中段: 店名/場所 + 外部リンク
- 下段: フレーバー一覧（画像と名前を横並び）
- 末尾: アクションメニュー（編集/削除/共有/詳細）

## コンテンツ仕様
- 満足度: 絵文字/アイコンは5段階固定、数値より視覚優先
- ミックス: フレーバー名と画像を並べる（比率/グラフは表示しない）
- 位置情報: 店名と外部リンクは同一行で省スペース表示
- メモ: 1行要約をカード内に表示、長文は詳細へ

## 状態
- 空状態: 「この日の記録はまだありません」+ 追加CTA
- 読み込み: スケルトン3件分（カード形状に合わせる）
- エラー: トーストで通知し再試行導線を提示

## 操作
- カレンダー日付クリックで開く
- Esc/背景クリックで閉じる
- カードクリックで記録詳細へ遷移
- 共有はX投稿とリンクコピーを同一メニューに集約
- 主要CTAは常に最上部と最下部に配置し迷いを減らす

## レスポンシブ
- PC: 2カラム（左: サマリー+一覧、右: 詳細/メモ）を優先
- SP: 1カラム、重要情報のみ折りたたみ可能

## モーション
- ダイアログ表示時に軽いフェード + スライド
- 一覧は段階表示で情報量の圧迫感を軽減

## 追加アイデア（検討用）
- 日内タイムライン: 時刻順に並べ、セッション間の空白を線で表現
- クイック絞り込み: 場所/満足度/ミックスでチップ切替（一覧内の視認性向上）
- 前後日ナビ: モーダル内で「前日/翌日」移動し文脈を維持
- 連続記録の強調: 同一ミックスが連日続く場合にバッジ表示
- メモ優先表示: メモがある記録はカードの冒頭に要約を出す
- 共有の下書き: X投稿のプレビューを簡易表示して離脱を防ぐ

## アクセシビリティ
- フォーカストラップと閉じる操作の明示
- コントラストはAA準拠、フォーカスリングを必ず表示
- アクションメニューはキーボード操作可能にする
