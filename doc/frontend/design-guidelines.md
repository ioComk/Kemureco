# 全体デザイン仕様（ガイドライン）

## 1. 目的
- Kemureco全体の世界観を統一し、ページ間の移動でも違和感のない体験を作る
- 「静かな上質感」「紙質感」「暖かい余韻」を軸に、情報量の多い画面でも読みやすさを保つ

## 2. コアコンセプト
- トーン: 暖色系・落ち着き・香りの余韻
- 質感: 紙/布の柔らかさを感じる面
- 余白: 呼吸感のある余白で“静けさ”を演出

## 3. タイポグラフィ
- 見出し: Kaisei Decol
- 本文: Zen Kaku Gothic New
- 文字サイズ
  - 大見出し: 28-40px
  - 中見出し: 20-24px
  - 本文: 14-16px
  - 補助: 12px
- 行間: 1.6-1.9を基準に読みやすさ優先

## 4. カラー
- ベース: ベージュ/ブラウン
- アクセント: 深いグリーン
- 重要なCTA: ダークブラウン（ライト時）/ 明るいベージュ（ダーク時）
- 背景: 単色ではなく、淡いグラデーションやぼかし円で空気感を作る

## 5. レイアウト
- 最大幅: 960-1200pxを基準
- 余白: 16-24px（SP）/ 24-40px（PC）
- セクション間: 40-64px
- カード: 角丸（24-32px）と柔らかい影

## 5.5. レスポンシブ対応
- ブレークポイント（目安）: 360px / 768px / 1024px / 1280px
- レイアウト: SPは1カラム、タブレット以上で2カラム以上を検討
- 余白: SPは上下を厚めに確保し、PCは左右の余白で読みやすさを調整
- 文字サイズ: SPは本文14-15px基準、見出しは段階的に縮小
- タップ領域: 44px以上を確保し、密度を上げすぎない
- 画像: 背景装飾はSPで弱め、読みやすさ優先
- 固定要素: SPでは固定ボタンやメニューの高さを最小化

## 6. コンポーネント指針
- ボタン
  - 主CTA: 塗りつぶし、強いコントラスト
  - サブ: アウトライン/ゴースト
- カード
  - 枠線は極薄または透明に近い色
  - 影で面を表現し、枠で囲みすぎない
- フォーム
  - 入力欄は大きめ、ラベルは必須

## 7. モーション
- スクロール時に軽いフェード/スライド
- 重要なエリアのみ段階表示（過剰な演出は避ける）

## 8. アクセシビリティ
- コントラストはWCAG AA相当を維持
- フォーカスリングの視認性を確保
- 入力エラーはインライン+トーストで補助

## 9. 禁止事項
- 紫系の主配色を使わない
- 強いネオンや過度なグラデーション
- 角の強い罫線で囲いすぎるデザイン
